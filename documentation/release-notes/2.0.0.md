# 2.0.0

`TimeWarp.Terminal` and `TimeWarp.Terminal.Layout` target `net11.0` only.

## Breaking

- `net10.0` is no longer a target. Projects on `net10.0` stay on 1.0.2.
- There is no multi-target package. One framework ships.

## Unchanged

- Public API of `IConsole`, `ITerminal`, `Terminal`, widgets, and `TimeWarp.Terminal.Layout`.
- `TimeWarp.Terminal` still depends only on `TimeWarp.Builder` 1.0.0.
- `TimeWarp.Terminal.Layout` still depends on `TimeWarp.Terminal` and `TimeWarp.Flexbox` 1.0.0.
- Both packages stay `IsAotCompatible` with trim and AOT analyzers enabled.

## Toolchain

- SDK pin: `11.0.100-rc.3.26522.148` in `global.json` (`rollForward: latestFeature`, `allowPrerelease: true`).
- `Microsoft.CodeAnalysis.NetAnalyzers` `11.0.100-rc.3.26522.148`.
